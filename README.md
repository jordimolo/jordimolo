## Proyectos destacados
 
**TFG — Plataforma de identificación de aves con IA** (en curso)
Proyecto de ciencia ciudadana desarrollado con varios estudiantes. Responsable de todo el cloud: backend, frontend, base de datos relacional, seguridad, dockerización de los servicios, colas de IA con Redis y almacenamiento en MinIO.
 
**[Flysy](https://flysy.software)** — Sistema de gestión y reserva de vehículos automatizados para un aeropuerto ([código](https://github.com/PTIN-TerminalA))
Proyecto de Tecnologías de la Información en equipo. Desarrollo del frontend de la web y del backend de la web y la app; roles de Scrum Master y Product Owner en distintos sprints.
 
**EduConnect** — Plataforma de grupos de estudio
Aplicación en C++ con .NET (Windows Forms), arquitectura hexagonal y patrón repository. Metodología Scrum + GitFlow con integración continua en GitHub Actions.
 
**ALMA** — Robot social asistencial para personas mayores
Diseño conceptual de un robot de acompañamiento doméstico con navegación social y expresividad emocional. Demo funcional con un mBot2 y una app web que sigue al usuario por cámara; conversación por voz mediante un LLM local (Ollama).
 
**[Conecta 4 y Path of Hexile](https://github.com/khaledmalhal/Path-of-Hexile)** — Bots de IA para juegos de mesa
Dos bots en Java basados en Minimax con poda alfa-beta; el de Hex combina además Dijkstra para evaluar el camino óptimo hacia la victoria.
 
Más detalle, capturas y diagramas de estos y otros proyectos (sistema IoT sobre ESP32, PetitFlix, bancada de motos eléctricas E3TEAM...) en el [portfolio](https://jordimolo.github.io).
